# Development Roadmap

- **Phase 1 — Project setup**: folder structure, asset organization, font/library loading strategy.
- **Phase 2 — Design system**: color tokens, type scale, spacing scale, button/card primitives (`style.css` root).
- **Phase 3 — Homepage shell**: navbar, mobile drawer, footer, section scaffolding.
- **Phase 4 — Three.js hero**: cup + bean meshes, lighting, cursor-driven parallax, mobile bean-count reduction.
- **Phase 5 — Menu**: category tabs, item data, tab-switch animation.
- **Phase 6 — Specialty coffee**: horizontal carousel, arrow controls, click-through info modal.
- **Phase 7 — Gallery**: responsive mosaic grid, lightbox with keyboard + swipe support.
- **Phase 8 — Reviews**: slider with autoplay, dot navigation, touch swipe, pause-on-hover.
- **Phase 9 — Reservation**: validated homepage form, loading state, toast feedback.
- **Phase 10 — Separate contact page**: `contact.html/.css/.js`, matching branding, own validated form.
- **Phase 11 — Python backend**: Flask app, `/api/contact` and `/api/reservation`, CORS, `.env` config, SMTP-optional email.
- **Phase 12 — Responsive testing**: breakpoints from 320px through 4K, no horizontal scroll, no overlap.
- **Phase 13 — Final optimization**: reduced-motion support, lazy-loaded gallery images, focus states, doc pass.
